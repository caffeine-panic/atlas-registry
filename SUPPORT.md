# Support

## Usage questions

Use [GitHub Discussions](https://github.com/caffeine-panic/atlas-registry/discussions) for installation help, connection questions, and workflow advice. Search existing discussions and documentation first.

## Bugs

Use the bug report form for reproducible product defects. Include the Atlas Registry version, operating system, adapter, server version, and minimal steps.

Never paste production resource values, passwords, tokens, private keys, credential files, or private endpoints. The in-app diagnostic export is intentionally redacted and is preferred over raw logs.

## Security

Do not report vulnerabilities in public issues or Discussions. Follow [SECURITY.md](SECURITY.md) and use GitHub private vulnerability reporting.
